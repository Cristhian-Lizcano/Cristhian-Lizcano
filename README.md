# ¡Hola! Mi nombre es Cristhian Lizcano 
###  Full Stack Developer

Ingeniero y desarrollador Full Stack orientado a la construcción de software web escalable, modular y mantenible. Mi enfoque va más allá de escribir código: me especializo en diseñar arquitecturas limpias, implementar sistemas de autorización granulares, automatizar flujos de datos y garantizar entornos de despliegue estandarizados.

---

### 🧠 Enfoque Técnico y Capacidades Clave

* **Autenticación y Seguridad:** Flujos de autenticación robustos basados en **JWT** (JSON Web Tokens), rotación de tokens y manejo seguro de credenciales.
* **Control de Acceso Avanzado:** Sistemas de autorización declarativos y dinámicos (**RBAC / ABAC**) integrando **CASL**, permitiendo la definición de permisos finos desacoplados en el backend y frontend.
* **Modelado y Persistencia de Datos:** Diseño de bases de datos relacionales en **PostgreSQL**, optimización de consultas, gestión con **Prisma ORM** y control de esquemas mediante **migraciones automatizadas**.
* **Arquitectura Serverless y Asíncrona:** Aislamiento de procesos pesados, tareas programadas o microservicios independientes utilizando **AWS Lambda functions** para optimizar costos y cómputo.
* **Contenedorización y Entornos:** Configuración de entornos de desarrollo y producción mediante **Docker** y **Docker Compose**, asegurando arquitecturas portables y listas para desplegar.
