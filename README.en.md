# Hi! My name is Cristhian Lizcano 👋

### Full Stack Developer

Engineered Full Stack Developer focused on building scalable, modular, and maintainable web applications. My approach goes beyond writing code: I specialize in designing clean architectures, implementing fine-grained authorization systems, automating data workflows, and ensuring standardized deployment environments.

---

### 🧠 Core Technical Focus & Capabilities

* **Authentication & Security:** Robust authentication flows based on **JWT** (JSON Web Tokens), token rotation, and secure credential management.
* **Advanced Access Control:** Declarative and dynamic authorization systems (**RBAC / ABAC**) integrating **CASL**, enabling fine-grained permission definitions decoupled across backend and frontend.
* **Data Modeling & Persistence:** Relational database design in **PostgreSQL**, query optimization, data management with **Prisma ORM**, and schema version control via **automated migrations**.
* **Serverless & Asynchronous Architecture:** Isolation of heavy background processing, scheduled tasks, or independent microservices using **AWS Lambda functions** to optimize compute costs and performance.
* **Containerization & Environments:** Development and production environment orchestration using **Docker** and **Docker Compose**, ensuring portable, production-ready setups.
